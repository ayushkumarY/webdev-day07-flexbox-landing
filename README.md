# Fieldnotes Flexbox Landing Page

A responsive landing page built for the Day 7 Flexbox assignment. It demonstrates a flex navigation bar, a wrapping hero layout, product cards using `flex-wrap`, `flex-grow`, and `flex-basis`, pricing cards, and a centred login form.

## Run it

Open `index.html` in a web browser. The page is self-contained; its photos load from Unsplash and therefore require an internet connection.

## Included interactions

- The navigation menu collapses to a toggle button on smaller screens.
- The login form displays a demo confirmation when submitted; it does not authenticate or save account data.

## Flexbox concepts

- `display: flex` with `justify-content` and `align-items` for navigation and alignment.
- `flex-wrap` for the hero, product listing, pricing cards, and form.
- `flex` grow and basis values for responsive cards that reflow as the viewport changes.
